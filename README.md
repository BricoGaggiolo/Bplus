# B+ Gestionale HR

Gestionale HR per la rete Brico+ (Gaggiolo · Cocquio · Daverio · Varese).

## 🚀 Accesso rapido

👉 **[Apri il gestionale](https://bricoGaggiolo.github.io/Bplus/)**

## Funzionalità principali

- Gestione turni settimanali per negozio
- Calendario assenze e ferie con approvazione
- Storico turni pubblicati con domeniche lavorate
- Dashboard per ruolo (Titolare / Direttore / Lavoratore)
- Notifiche push per turni e assenze
- Corsi con gestione partecipanti
- Punti vendita con orario continuo/spezzato
- App mobile-friendly (PWA)
